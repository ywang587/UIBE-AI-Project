## 接续目标

交付可运行的课程 demo：单条财经视频解读、满足条件时的跨作者对照，以及已导入资料的事件简报。首版允许手动导入视频；不以完美采集、商业可靠性或独立准确率评估作为首版交付门槛。用户已选择本地模型，不使用付费分析 API，并要求自主修复问题、将代码与验证进度上传 GitHub。

原先无法读取本地课程文件夹的问题已解除。当前任务分支为 `codex/local-pipeline-validation`，PR 为 #1。可复用代码不写入个人电脑的绝对路径。公开仓库只保存代码和去除私人信息的验证记录，不上传原视频、模型、数据库、Cookie 或登录资料；不得登录用户提到的第三方视频查询平台。

## 当前实现

2026-10-14 复现补齐：从 GitHub 主入口重新克隆并切换程序分支，独立 Mac Python 3.11 环境通过 53 项工程测试、自动合成页面检查和真实语音→转录→Qwen 短流程。新增 `docs/REPRODUCING.md`、可执行 smoke 脚本、依赖快照和历史公开输入指纹清单；只复用公开权重与浏览器缓存，不复制旧资料库或视频。详情见[本轮复现检查](validation/2026-10-14-reproducibility.md)。

2026-10-13 使用体验更新：在用户启动的分析正常完成后才修改程序。首页过滤宏观无关视频，关注页保留已导入的更新历史；详情默认显示最多三条模型已选重点，完整分类与证据折叠。阅读副本统一简体，下载和原始文件不变。新建不继承 Conda 包的环境验证依赖、53 项测试与转录组件导入；安装说明补齐正确 GitHub 分支、Apple Silicon/macOS 15+ 要求、模型缓存及可选 MediaCrawler 登录。此前测试视频不上传，也不是新设备运行前提。见[本次显示与安装验证](validation/2026-10-13-display-and-install.md)。

“观潮”本机应用已有文件与链接导入、串行下载/转录/分析、哈希去重、失败重试、原视频播放及时间定位、历史记录、关注作者、运行期间定期检查和启动补查。自动处理新发现可在设置中开启；本机当前关闭该选项，以免积压作品同时触发长时间推理。

默认使用 Faster-Whisper medium 与 MLX Qwen3 4B Instruct 2507 量化模型，无需 API 密钥。Apple Silicon 已实测；Windows/Linux 的本地分析后端尚未实现。路径可配置，GitHub 同步不包含运行数据。

分析保留事实性主张、解释、评价、预测与推广，以及连续原文、条件、期限和未解决问题。未通过原话检查的草稿单列，不进入摘要、事件简报或对照。完全相同的主张和证据出现类别冲突时，显示“分类待复核”。摘要从全片已有主张中选取最多三条，原句复用，不补写市场机制。

对照先判断事件、问题、期限和条件；自动选择少量候选，也支持手动选两条视频。事件简报只汇集已导入资料。涉及美国债务规模时，分析完成后另取美国财政部免费公开数据，显示记录日期和原始美元数值；官方背景不参与博主主张提取或对照，也不是自动事实核查。

## 本轮验证

- 既有四条真实视频保存在本机应用：三条财经内容、一条无关生活内容。最长约 15 分半；下载、转录、分析及页面回放已有实际记录。
- 指定 Kevin 主页的实际初查发现 14 条作品，重启补查也已运行；失败及分页覆盖不完整时不推进成功检查点。有界分页不保证穷尽历史作品。
- 新增两条不同作者、共同讨论美国债务与经济增长的视频，长度约 659 秒和 430 秒，均已完成 medium 转录。稳定作者哈希确认两者不是同一作者。
- 当前完整重跑使用 `evidence-v9-context-overlap`。第一条完成：49 条主张、21 项事件、12 条待复核草稿，分析耗时 1934.322 秒。此前把 GDP 增长误写为债务增长的问题，在补入相邻上下文后恢复了正确主体。第二条完成：25 条主张、11 项事件、6 条待复核草稿，用时 1336.455 秒。两条新结果已导入本机历史库，连同原先四条共六条。
- 50 项工程检查通过，包括摘要编号选择、分别选取双方依据、引用编号限制和条件/期限不匹配时拒绝直接分歧。工程通过不等于真实内容准确。

本轮完整结果、失败尝试与原始输出保存在本机 `local_data/pair-analysis-context/`，正式资料库为 `local_data/app/`。默认对照为 `comparison-v4-coexistence`：先选择共同问题和双方依据，再检查可比性及是否能同时成立。本例为“互补”，期限和条件未确认一致。先前两次错误“分歧”保留为失败记录，没有导入应用。自由生成的对照解释保留为草稿，页面使用关系标签、核对提示和原文，详见[真实长视频与对照验证](validation/2026-10-13-real-pair.md)。不要重新转录已完成样本。

## 已知局限与后续

真实材料仍出现类别错误、期限字段不当、反问句被列为主张，以及语音识别的数字和年份错误。第一条新视频在约 3.8 秒处，转录年份与画面字幕不一致；原转录保留，不能用视频发布日期替代事件年份。引用存在、数字匹配和模型自检都不能证明原意得到完整保留。

首版流程已跑通并有可直接查看的本机样本：单条解读、有条件对照、事件简报、原文与实际视频播放均已检查。390 像素布局和实际历史库检查通过。后续改进重点是提取/对照质量、摘要覆盖、长时间运行和平台异常恢复；当前不是已验证准确率的金融分析工具。

自动语义审查实验在 Qwen3 上仅通过 9/15 个合成案例，Qwen3.5 上为 8/15，且会误拒绝正常主张，因此没有启用。实验性的期限/资产字段限制也没有默认启用，不作为首版运行的前置条件。默认模型未因下载候选模型而改变。
