# 2026-10-13 官方背景与作者身份

## 已实现及验证

原讨论允许外部背景，但不允许程序替博主补造市场机制。本轮为明确涉及美国债务规模的分析补充美国财政部 Debt to the Penny 数据。背景在主张提取结束后获取，不传回提取模型，也不进入博主观点对照的输入。

实际公共接口返回一条日期为 2026-10-08 的记录，金额为美元字符串：公众持有债务、政府内部持有债务及总额。程序校验日期、非负有限数值与分项加总，保留获取时间和记录指纹。详情页显示带日期的背景卡片，约数用万亿美元表示，原始美元数值可展开；来源链接固定到该记录日期。见 [接口快照](2026-10-13-official-background.json)及[官方数据集](https://fiscaldata.treasury.gov/datasets/debt-to-the-penny/)。

这是背景资料，不是自动事实核查：数据可能晚于视频事件；视频发布日期没有被用作事件日期；官方债务总额不能证明博主的市场机制。接口失败时单列获取失败，保留视频主张，不将失败解释为主张正确或错误。当前只接入这一项主题明确的官方数据源，没有声称覆盖全部宏观背景。

浏览器使用真实接口快照与候选视频分析作为展示测试：背景与博主原意分开、原始金额和日期可见、390 像素宽度无横向溢出；模拟接口失败后主张继续显示，无 JavaScript 错误。见 [界面检查](2026-10-13-background-browser.json)。该展示测试没有覆盖应用中的旧分析记录。

## 作者身份修复

核查本机课程下载器发现，它主动遮蔽昵称，并把作者 UID 的 SHA-256 前 16 位作为稳定标识保存。两条候选视频的新详情与原有记录一致，作者哈希不同。这里只验证标识关系，没有尝试恢复被遮蔽的姓名或 UID。

此前下载完成时，应用会用缺失的公开作者 ID 覆盖已关注作者的 ID，并可能以遮蔽昵称替换已知名称。现已保留已知作者身份，另存 `author_hash`；自动候选排除相同作者 ID 或相同作者哈希。旧数据库增加该字段，已有视频与队列保留。未知标识不能用来证明两个账号不同。

详情读取新增 `--metadata-only`，本轮两个候选均实际读取成功，不重复下载已有视频，不访问第三方视频查询平台。候选为视频 7693573120950603018 与 7694611088712666394；完整视频的语音转录与同事件对照仍在继续，尚不能报告对照成功。

随后检查发现，“关注与更新”中的手动导入只按链接入队，没有带上已关注作者信息。现已与自动导入共用同一入口，保存作者、发布时间和标题；已有记录仅补回缺失身份或遮蔽昵称，不重复创建处理任务，不覆盖已有稳定作者哈希。新增接口回归覆盖新视频、已通过链接导入的视频以及重复点击，全部工程检查增至 39 项通过。另根据精确视频 ID、已核验文件哈希和既有发现记录，为本机原有 4 条视频补回作者信息；修改前保存了本机恢复记录，未改动分析内容。

## 分析字段实验仍未启用

尝试在首次生成时把期限限制为原话中的时间选项，虽然避免了整句条件充当期限，却使真实样本中的条件警告消失，并出现原文未明确提出的未来推断。不能把局部字段变好当成整体质量提高，因此没有启用该方案。

后续候选仅在逐条修正时使用时间选项，并检查金额/百分比不能作为资产名称。它以 `--experimental-source-fields` 显式开启，记录为 `evidence-v8-targeted-fields`；默认应用仍使用 v7。这是实验分支，不是新默认方法，真实回归尚在等待串行任务完成。规则仅覆盖常见中文时间形式；没有匹配不等于原文没有时间信息。
