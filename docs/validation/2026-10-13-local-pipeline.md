## 分析样例与验证

本地印度样例由开发 AI 根据转录整理为四项主张，区分事实性主张、解释和评价。每项附原文与时间位置；外部背景和跨博主对照明确标为尚未建立。

`evidence_report.py` 检查源视频哈希、分析与转录来源，以及引文是否存在于对应片段中，再生成可点击时间回看视频的 HTML。浏览器实测视频时长约 37.012 秒、画面宽度 1080、点击后跳到 6.94 秒附近；390 像素窄屏无横向溢出，并已检查报告截图。

这份样例不是运行时自动分析：当前没有模型 API 调用、自动事实核查或跨视频比较。引文校验通过也不等于观点提取正确。
